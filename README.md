# FairFielding v0.9.1
Youth baseball defensive rotation and Game Day tracker.

## New in v0.9.1
- Player Left Game from Game Day.
- Player Joined / Returned.
- Completed innings stay locked.
- Remaining innings regenerate from actual bench, INF/OF and position history.
- No-1B restrictions and remaining pitcher/catcher assignments are retained where possible.
- Live pitching bookkeeping remains included.

Upload all seven files to the same GitHub/Vercel project directory.

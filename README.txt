FairFielding v0.3

Fair defensive lineup generator for youth baseball.

v0.3 changes:
- Added JW, Gino, and James to the default roster
- Added season-long fairness tracking using browser localStorage
- Tracks INF, OF, bench, and individual positions across saved games
- Previous saved games influence future lineup generation
- Added Save This Game so test generations do not alter history
- Added visible Season History
- Added Reset History with confirmation
- Keeps 9-player and 10-player field support
- Keeps pitcher/catcher locks and No 1B restrictions

Important:
Season history is stored on the device/browser where the game is saved. Clearing website data or using another device/browser will not carry the history over.

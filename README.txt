FairFielding

Current build: v0.9.0

Adds lightweight live pitching bookkeeping to the working v0.8.2 Game Day experience.

Features:
- Fair defensive rotation generation
- 9 or 10 defensive players
- P/C locks and No 1B restrictions
- Season fairness history
- Stadium Game Day
- Live substitutions and unavailable-player handling
- Pitch count
- Ball/strike count
- Fouls
- Strikeouts
- Walks
- Hits allowed
- Runs allowed
- Batters faced
- Undo last bookkeeping action
